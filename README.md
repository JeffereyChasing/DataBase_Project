# Apartment Search Web Application

## Overview

The Apartment Search Web Application is a comprehensive solution designed to simplify the process of finding apartments based on various user-defined criteria such as the number of bedrooms, pet policies, and more. This application leverages HTML, CSS, and JavaScript for the front-end, a custom API built with Python for the back-end, and a MySQL database for data storage. Enhanced security measures, including bcrypt hashing and parameterized queries, are implemented to ensure secure user login and data handling.

## Features

### Front-End
- **Search Functionality**: Users can search for apartments based on various criteria including:
  - Number of bedrooms
  - Pet policies
  - Price range
  - Location
- **User Interface**: Designed and implemented using HTML, CSS, and JavaScript to provide a responsive and user-friendly experience.

### Back-End
- **Custom API**: Built using Python to handle data requests and interactions between the front-end and the database.
- **Database Schema**: MySQL database designed to store user input and apartment details efficiently.

### Security
- **User Login System**: Implemented a secure login system that uses bcrypt hashing for password security.
- **Parameterized Queries**: Applied to prevent SQL injection attacks and ensure secure database interactions.

## Technologies Used
- **Front-End**: HTML, CSS, JavaScript
- **Back-End**: Python
- **Database**: MySQL
- **Security**: bcrypt hashing, parameterized queries
